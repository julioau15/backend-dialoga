# DiaLoga - Backend

Este repositório contém o backend do DiaLoga, uma aplicação desenvolvida como parte do Trabalho de Conclusão de Curso (TCC).

O DiaLoga é uma plataforma que busca facilitar a interação e o acompanhamento entre pacientes e profissionais por meio da tecnologia.

---

## Repositórios do Projeto

O projeto está dividido em três aplicações:

* **Repositório principal:** https://github.com/julioau15/dialoga
* **Backend:** [github.com/julioau15/backend-dialoga](https://github.com/julioau15/backend-dialoga)
* **Frontend:** [github.com/julioau15/frontend-dialoga](https://github.com/julioau15/frontend-dialoga)
* **Mobile:** [github.com/julioau15/mobile-dialoga](https://github.com/julioau15/mobile-dialoga)

---

## Sobre o Backend

O backend é responsável pelo processamento das informações e pelas regras de negócio do DiaLoga.

A aplicação disponibiliza uma API responsável pela comunicação entre o frontend, o aplicativo mobile e os demais recursos necessários para o funcionamento da plataforma.

---

## Objetivo

Desenvolver uma API responsável pelo gerenciamento das informações, regras de negócio e funcionalidades utilizadas pelas aplicações do DiaLoga.

---

## Como Executar o Projeto

### 1. Clone o repositório

```bash
git clone https://github.com/julioau15/backend-dialoga.git
```

### 2. Acesse a pasta do projeto

```bash
cd backend-dialoga
```

### 3. Instale as dependências

```bash
npm install
```

### 4. Execute o projeto

```bash
npm run dev
```

Após iniciar o projeto, a API estará disponível no endereço configurado pela aplicação.

---

## Comunicação com as Aplicações

O backend disponibiliza a API utilizada pelas aplicações do DiaLoga.

### Frontend

O frontend web utiliza a API do backend para realizar operações e obter as informações necessárias para o funcionamento da plataforma.

[Frontend do DiaLoga](https://github.com/julioau15/frontend-dialoga)

### Mobile

O aplicativo mobile também utiliza a API do backend para comunicação com o sistema.

[Mobile do DiaLoga](https://github.com/julioau15/mobile-dialoga)
